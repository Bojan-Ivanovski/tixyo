Short answers about how Tixyo approaches GitHub issue classification and routing.

What is AI issue triage?

AI issue triage analyzes an issue’s title, description, and discussion to recommend structured metadata such as type, priority, size, components, risk signals, and ownership.

Does Tixyo change GitHub issues automatically?

Not by default. Tixyo starts in dry-run mode, displays each recommendation and confidence score, and only writes eligible changes when you explicitly use --apply.

Can an issue have multiple components?

Yes. Tixyo treats component classification as multi-select, so one issue can affect areas such as source code, builds, tests, and documentation at the same time.

How do I install the Tixyo CLI?

Install it from PyPI with pip install tixyo, provide a GitHub token and repository, then run tixyo triage ISSUE_NUMBER to preview a decision.
